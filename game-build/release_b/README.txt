@SHORT@ PC @VERSION@

1. Run @LAUNCHER_EXE@ and pick your dump folder (base/ and updates/<version>/, each with exefs/ and romfs/). Version @DUMP_VERSION@ is required.
2. Press Set up. It builds @EXE@ and the shader cache on this PC. You can pause and continue later.
3. Press Play.

Upscaling: FSR 3 works out of the box (F1, Graphics). DLSS / DLAA need an NVIDIA RTX GPU and a file NVIDIA licenses separately: the launcher's Game files page has a button that downloads it from NVIDIA.
